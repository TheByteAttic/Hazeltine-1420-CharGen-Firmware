# Gerbers

Upload each zip to JLCPCB exactly as it is (no renaming, no unpacking):

| Zip | Board |
|-----|-------|
| `h1420-chargen-U26-upper-gerbers.zip` | adapter for the upper socket U26 (body bends upward) |
| `h1420-chargen-U25-lower-gerbers.zip` | adapter for the lower socket U25 (body bends downward) |

Order options: 2 layers, 1.6 mm, any colour, HASL or ENIG, no castellation, no stencil needed
(the SOICs are hand-soldered). Minimum order is 5 boards per zip.

Each zip contains: F_Cu, B_Cu, F_Mask, B_Mask, F_Silkscreen, B_Silkscreen, Edge_Cuts (RS-274X Gerber,
mm, 4.6 format) and PTH.drl (Excellon, plated through holes: 1.0 mm plug pins and socket, 0.3 mm vias).

These files were generated by `../../source/export.py` from the routed layouts and were verified
directly from these Gerbers (`../../docs/verification-report.txt`): reconstructed netlist, structural
simulation, DRC and an independent short/open check.
